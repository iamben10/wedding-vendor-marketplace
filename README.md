# Wedding Vendor Marketplace

A beautiful, responsive wedding vendor marketplace built with HTML and Tailwind CSS.

## Features

- Responsive design that works on all devices
- Navbar with Home, Vendors, and Contact sections
- Hero section with search functionality
- Popular vendor categories
- Featured vendor grid with ratings, prices, and booking options
- Integrated UPI payment system with 5% platform commission
- Google Form integration for vendor signup
- Mobile-friendly navigation

## Technologies Used

- HTML5
- Tailwind CSS
- Font Awesome Icons
- UPI Payment Integration

## Screenshots

The website features a clean design with a focus on showcasing wedding vendors across various categories including photography, catering, venues, music, bakery, and planning services.

## How to Use

1. Browse the available vendors
2. Click "Book Now" to make a payment via UPI
3. Vendors can sign up using the embedded Google Form

## UPI Payment System

The marketplace features direct UPI payment integration with:
- Pre-filled payment links with vendor details
- Automatic 5% platform commission
- Secure transaction processing
